# E-Commerce Customer Churn & Revenue Risk Analysis

## Project Overview
This project predicts customer churn for an e-commerce platform using Python Machine Learning and visualizes key risk metrics in an interactive Power BI dashboard.

## Tech Stack
- *Data Processing & ML:* Python (Pandas, Scikit-Learn)
- *Database Analysis:* SQL
- *Data Visualization:* Power BI Desktop

## Key Insights
- *Average Churn Probability:* 32%
- *High-Risk Segment:* Customers with Month-to-Month contracts have the highest likelihood of churning.
- *Actionable Strategy:* Focus retention campaigns on short-term contract subscribers to increase customer lifetime value.

## Repository Contents
- data_cleaning.py: Python script for data preprocessing.
- 03_ml_model.py: Random Forest Machine Learning model implementation.
- sql_analysis.sql: SQL queries for database exploration.
- Ecommerce_Churn_Dashboard.pbix: Power BI Interactive Dashboard.
